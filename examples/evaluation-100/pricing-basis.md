# Pricing basis

Checked 8 November 2026 against [OpenAI API pricing](https://developers.openai.com/api/docs/pricing).

The estimate uses `gpt-6.1-terra` Standard short-context rates: US$1 per million input tokens and US$5 per million output tokens. It applies these rates to the token usage returned for every request. Cache discounts and provider billing adjustments are not applied.

The monthly illustration uses the mean of all 100 evaluated attempts, including the failed attempt, multiplied by 20 workdays with one task each day. It excludes desktop hosting, setup and video or narration production. The earlier pilot is excluded from the 100-run calculation.
